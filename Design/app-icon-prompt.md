# App Store icon

Created with the built-in image generation tool using the existing PineappleMark PNG as the edit target. Original preserved. Exported mechanically to 1024 × 1024 pixels with `sips`; opaque RGB PNG. The header retains its transparent version.

Project asset: `MiTension/Assets.xcassets/AppIcon.appiconset/app-icon.png`.

## Final prompt

Use case: precise-object-edit. Edit target: supplied pineapple brand mark. Create the iOS App Store app icon for Mi Tensión. Preserve exactly this friendly golden pineapple character, green crown, blood-pressure cuff and monitor; do not redesign the character. Compose on a square 1024x1024 canvas, center the whole character occupying about 78% of height with breathing room all around. Add a solid opaque warm ivory background (#F3F8F7), extending to all four edges; no transparency. Keep crisp polished edges and small-size legibility. No rounded corners or outside border (iOS applies its own mask), no shadow outside the canvas. No letters, no numbers, no medical cross, no watermark. Return just the flat square app icon artwork.
